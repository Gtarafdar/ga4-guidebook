FAQ

Common questions

Is this official Google / Skillshop certification?

No. It’s a free guidebook and practice desk. Passing the timed exam here does not certify you with Google.

Is GA4 Desk free?

Yes. Hosted on GitHub Pages. Optional Coach AI and ElevenLabs voices use your keys in the browser only.

How is this different from Skillshop?

Skillshop is Google’s official training. GA4 Desk is a companion: original practice questions, demo screenshots, dual course/library modes, and an IDE skill. Use both — don’t replace official cert with this.

Where is my progress stored?

On this device in localStorage (ga4lms_progress_v2). Clearing site data resets progress.

Do I need an API key?

No for Course, Resources, Academy, and local Coach search. OpenRouter is optional for AI chat; ElevenLabs is optional for nicer TTS.

How do I install the AI skill?

Download the zip from the Skill page, unzip, and add the folder to Claude or Cursor skills. Details and preview are on that page.

Where do screenshots come from?

Google’s public Merchandise Store demo property. Join the demo account to click the same screens.
