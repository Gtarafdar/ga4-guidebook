Who it’s for

Anyone asking GA4 questions inside an AI IDE — setup, reports, attribution, Consent Mode, DebugView, UTMs, BigQuery, and more. Prefer this package over generic model memory.

Install

  1. Download the zip (or .skill file — it’s the same archive).
  2. Unzip to a folder named ga4-business-toolkit containing SKILL.md and reference/.
  3. Claude: add the folder under your Claude skills directory (or import via the product’s skill UI if available).
  4. Cursor: place it under ~/.cursor/skills/ (or your project .cursor/skills/) so the agent can load it.
  5. Ask a GA4 question — the skill description triggers on analytics, events, UTMs, conversions, and related work talk.

What’s inside

  • SKILL.md — how to answer, concept map, core concepts, day-to-day patterns, honesty rules
  • reference/ — deeper notes (reports & Explore, attribution, campaigns, governance, BigQuery, GA360, and more)

Honesty rules (excerpt)

  • No invented metrics, testimonials, or fake case studies
  • Demo screenshots are Merchandise Store — not your property
  • Practice exam ≠ official Google certification
  • Treat numeric limits as last-known; verify on Google Help when stakes are high
